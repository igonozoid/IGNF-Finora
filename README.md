# IGNF Finora

Gestão financeira pessoal para desktop (Python + PySide6).

- Edição **Free**: 1 usuário, banco SQLite local na pasta do app.
- Edições **Plus / Pro** (assinatura): ver `docs/EDICOES.md`.

## Rodar
```bash
python -m venv .venv && .venv\Scripts\activate   # Windows
pip install -e .
python -m finora
```
